# 공개용 증거의 개인정보 마스킹

공개 evidence 파일은 실행 원본에서 로컬 식별 정보만 치환한 사본이다.

| 항목 | 공개 사본의 표시 |
| --- | --- |
| 운영체제 사용자·그룹 이름 | labuser |
| PC 호스트 이름 | lab-host |
| 개인 프로젝트 절대 경로 | /workspace/linux-troubleshooting-lab |

시각, PID/TID, CPU·RSS·스레드 수, 환경변수 값, 종료 코드, 장애 메시지는 유지했다. summary.json을 다시 계산해 마스킹 이전의 수치 요약과 동일함을 확인했다. SHA256SUMS는 공개용 사본의 무결성을 검사하며, 개인 식별 정보가 포함된 실행 원본의 해시 목록으로 해석하지 않는다.

실행 스크립트는 앞으로 원본을 Git 제외 경로인 `.runtime/raw-evidence`에 기록하고 종료 후 마스킹된 사본만 evidence에 내보낸다. 도중에 중단되면 원본은 해당 비공개 로컬 폴더에 남는다. 자동 치환은 이 실습의 알려진 식별 필드를 대상으로 하므로 공개 전 개인정보 검사를 함께 수행한다.

커밋 작성자 이메일은 GitHub noreply 주소를 사용한다. 공개 파일과 커밋 메타데이터를 함께 확인해야 한다.
